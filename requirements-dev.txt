# Test-only dependencies. NOT installed into the runtime image, deliberately.
#
# THIS FILE EXISTS BECAUSE OF A CLASS OF BUG THAT HAS BITTEN THIS PROJECT TWICE. A
# developer interpreter accumulates packages that FastAPI's test extras pull in, so the
# suite passes locally against libraries the slim runtime image does not have. That is how
# python-multipart came to be missing in production while every test was green -- Starlette
# asserts on it for ANY form parsing, so every HTML form POST returned 500 for weeks.
#
# The rule now: requirements.txt is what the SERVICE needs, this is what the TESTS need,
# and CI installs them separately so the split cannot rot.
-r requirements.txt

# httpx-in-oauth crash-looped the container on deploy.
httpx>=0.28.1
